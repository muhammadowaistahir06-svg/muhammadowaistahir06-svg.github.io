Autonomous Kinematics & Embedded Control

September 14, 2026

The Constraint Standard robotic chassis rely on abstracted libraries and pre-packaged controllers. The objective was to build raw, deterministic finite state machines for autonomous navigation, avoiding high-level overhead.

Hardware Architecture

  • Designed physical maze-solving and line-follower chassis driven by bare-metal C/C++.
  • Integrated TB6612FNG motor drivers with 5-channel IR sensor arrays directly into the ESP32 GPIO layer.
  • Modeled custom 2DOF pan-tilt camera mechanisms and mechanical enclosures using Tinkercad and FreeCAD.

Control Logic & Simulation

  • Deployed parallel drone swarm simulators leveraging C++, MPI, and CUDA with WebGL visualization.
  • Implemented regression models and feature importance mapping for robotic path planning using Jupyter Notebooks.
  • Built ESP32-CAM real-time video streaming pipelines optimized for YOLOv8 object detection tasks.
